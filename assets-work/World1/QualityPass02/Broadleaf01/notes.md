# Broadleaf curve rebuild — accepted offline

Scope: Grass05 and Grass06, 399 placements in Lorencia. tree_09.OZT is frozen byte-for-byte. The prior Groundcover01 work improved the painted leaf but retained the original folded ribbon geometry.

The candidate replaces each of sixteen ribbons with a smooth longitudinal arc and a shallow center rib. The first study preserved every edge control and was rejected for retaining old elbows (see rejected-v1). The revised design retains endpoints and directional extrema, removes obsolete monotonic interior controls, and constructs long monotone cubic arcs with a six-unit faded center rib. Root and tip controls remain exact; each original bone clump retains its exact bounds. Four original roots, their action, original texture parameterization, and overall bounds remain. The alpha image supplies the tapered leaf outline. Triangle count is 640 per asset (112 before), within the foliage budget.

Official Blender 5.2.2 and SourceTools 3.4.3 import/export both models. The pipeline checks local skeletal motion as rotation matrices (equivalent Euler branches differ), action metadata, engine bounds, raw normal-to-vertex bone identity, frozen texture validation and exact cyclic triangle/material/bone/UV correspondence after reimport. Position comparison permits 0.0003 world units for six-decimal SMD Euler and float32 rounding; UV comparison remains within 0.000001. The final Grass05 export position drift is 0.0001415; UV drift is at most 0.000000507 (six-decimal interchange rounding). This is distinct from the authored control-point proof, whose root/tip error is exactly zero.

Actual candidate exports are reimported before matching-camera diffuse, reverse, reduced-size and wireframe renders. Independent visual and technical review accepted both final v2 exports, including the actual placement clusters (independent-final-review.json). Only Grass05.bmd and Grass06.bmd were installed into this isolated checkout after acceptance. Actual six-placement clusters are retained for Grass05 (indices 88,85,84,83,86,87) and Grass06 (58,59,64,61,62,60), using original positions, rotations and scales. Light/dark alpha comparisons show the frozen cutout edge without a new fringe. No client was opened; runtime performance and client verification remain pending.

Reproduce with the isolated official toolchain environment (MU_BLENDER, MU_BMDCONV, BLENDER_USER_SCRIPTS, BLENDER_USER_CONFIG), then run pipeline.py prepare followed by pipeline.py build. Run assemblies.py for Grass06, then with BROADLEAF_ASSEMBLY=Grass05 for Grass05; use Blender --factory-startup for these library-only renders. make_comparisons.py requires Pillow. Baselines and original packed source files are retained beside each asset; authored source.blend includes hidden REF_ORIGINAL and packed frozen texture.
